## 二、权威没写死、由用户 2026-10-07 裁定的口径

1. **栖途·再生换算**：`1 层再生 = +1 生命上限`（选项「推荐」）。
2. **栖途·敲后**：`3 费 → 2 费`（权威 L43 的「敲后」后面是空的）。
3. **焚烧·附加即时触发的伤害口径**：只算**该敌人自己当前的层数**（不按场上总层数），用户原话
   「1.刚改的，全都要」。
4. **红莲淬·附加比例与对象**：**全额 100%**、加到**当前携带的那把剑**（龙剑/魔剑都算）、本场一直保留。

## 三、实现侧必须记下的两个「口径判断」（可一键改回）

- **栖途的换算取「累计发放层数」而不是「战后剩余层数」**：引擎 `RegenPower` 每个我方回合结束都会
  `Heal(Amount)` 再 `Decrement` 1 层（实据 `RegenPower.cs:20-27`）⇒ 战斗结束时剩余层数通常只有 0~2，
  按它转化等于这张先古牌没有收益。日志同时打印两个数（累计发放 / 当前剩余），实机可核对。
- **归墟只给【嗜血魔剑】**：权威 L54 逐字写的是「转入**魔剑**的附加伤害」⇒ 未携带魔剑时，归墟只有
  「全场不能回血」这一半效果（这是设计内的取舍，不是漏实现）。

## 四、顺带修掉的旧问题

- `OrcaVoidReturnPatch.ActiveOnLocalPlayer` 的**裸 catch**（静默吞）→ 补 `OrcaLog.Warn`，行为不变。
- 红莲淬 / 睥睨 / 归墟 / 浴血涅槃 / 栖途五处的**旧口径注释与类摘要**全部按新权威重写，避免误导下一位读者。
- `OrcaHomesteadPower` 里随旧口径作废的 `_ratio` / `SetRatio` / 比例换算三件套**整段删除**（不留死代码）。
