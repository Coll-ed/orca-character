### 2.1 卷焰斩 `ORCA_ROLLING_FLAME` —— 数值整体偏低（★最严重之一）

**权威原文**（`说明2:20-23`）：
> 卷焰斩
> 2费，无色，白卡，攻击牌，敲后7攻8【焚烧】
> 对所有敌人造成5点伤害并附加6层【焚烧】
> 若此牌被消耗，则立刻打出一次

**代码实际**（`Cards-Pack2.cs:158-172`、`:232-237`）：

```csharp
private int _burn = 3;                                        // L158
public OrcaRollingFlame() : base(2, (CardType)1, (CardRarity)2, (TargetType)3) { }   // L170
protected override IEnumerable<DynamicVar> CanonicalVars => new[] { new DamageVar(4m, (ValueProp)8) };  // L172
protected override void OnUpgrade() { DynamicVars.Damage.UpgradeValueBy(3m); _burn = 5; }               // L233-237
```

**具体差在哪**

| 项 | 权威 | 代码 | 卡面文案 |
| --- | --- | --- | --- |
| 基础伤害 | **5** | 4 | `{Damage:diff()}`（自动跟代码 ⇒ 4） |
| 基础【焚烧】 | **6** | 3 | `{Burn:diff()}`（自动跟代码 ⇒ 3） |
| 敲后伤害 | **7** | 7 | 7 |
| 敲后【焚烧】 | **8** | 5 | 5 |

⇒ 代码与卡面**彼此一致**（无"爆变量"），但两者一起与权威不符；基础伤害、基础焚烧、敲后焚烧三项全错。
⚠️ 同一文件 `Cards-Pack2.cs:146` 的类注释也写着旧口径 `"对所有敌人造成 4 点伤害并附加 3 层【焚烧】…敲后 7 攻 5 焚烧"` —— **注释跟着代码一起错**，说明这卡从未按权威回读。

**建议怎么改**：`DamageVar(4m)` → `DamageVar(5m)`；`UpgradeValueBy(3m)` → `UpgradeValueBy(2m)`（5→7）；`_burn` 初值 `3` → `6`；`OnUpgrade` 里 `_burn = 5` → `_burn = 8`。同步修 `Cards-Pack2.cs:146` 注释。
